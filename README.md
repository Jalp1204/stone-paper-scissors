# Rock Paper Scissors

A fun Rock Paper Scissors game built using HTML, CSS, and JavaScript.

## Features

* Play against the computer
* Random computer choices
* Live score tracking
* Draw counter
* Reset scoreboard
* Animated computer thinking effect
* Responsive and interactive UI

## Technologies Used

* HTML
* CSS
* JavaScript
